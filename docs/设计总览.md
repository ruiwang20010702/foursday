# Foursday 设计总览

## 产品定义

Foursday 是“个人记忆驱动的工作分身”：可信联系人提出工作，Foursday 自动找到项目，由 Codex 唯一工作循环完成可恢复工作，并用真实证据回复。

默认个人模式不使用项目 capability manifest、逐联系人项目授权或固定业务指标。企业治理可以未来作为独立插件提供，但不进入个人安装主路径。

目标职责是：Hermes负责消息入口、Session、Cron、事件触发与结果投递；Codex负责Thread、工作范围选择、子Agent、Shell/Python、Web、图片、MCP、Skills、运行记忆、项目工作与自然回复；Foursday只负责稳定身份、真实workspace绑定、任务授权范围、人工沟通/任务所有权、高风险出口、外部回执和gbrain稳定事实晋升。

当前源码候选版本为`v0.9.0-rc.3`，最新 GitHub Release 仍为`v0.8.0-rc.1`。源码验收、GitHub Release、某台实例的技术部署和生产激活是相互独立的状态。

桌宠的“设置与系统诊断”统一读取Control Service的状态、任务、计划、记忆和证据投影。普通层只出现行动语言，技术详情折叠后才显示Shadow/Active、Checkpoint、Event Wake、reaction、固定绑定、可发现项目、提交和错误码。记忆口径仍分为固定绑定范围/页面与个人gbrain可发现项目数；可发现数量不授予文件系统权限，目录临时不可用只降级该计数，不影响消息服务。

## 自主与询问

- 任务范围内可恢复工作默认自主执行，不逐工具审批。
- 当前企业成员通过稳定身份验证后默认进入；其直聊提供的精确钉钉链接自动成为本轮只读来源。
- 企业消息只含OpenID时必须在当前组织候选中唯一反解staff ID；瞬时身份服务故障进入私有有界隔离队列，永久拒绝和外部联系人不进入Codex。
- 同一次启动或精确历史回放先按reconcile批次聚合同会话消息，再由无工具Codex按连续任务语义分组；每组另给出`action_required|no_text_reply`语义责任证据。它只防止可执行请求被误静默，主Codex仍负责理解、工具调用和自然回复，程序不写业务关键词或固定答案。
- 任务标题、目标、交付物、验收条件、返工和升级由Codex结合完整上下文判断；身份、工作区、版本、状态合法性、最小证据和高风险出口由程序确定性约束。桌宠工作现场只投影任务与脱敏App Server活动，不参与业务判断；暂停、恢复和接管仍由Control revision/CAS执行。
- Hermes保留通用授权框架，但DWS不使用pairing：Adapter只给已通过企业/显式用户门禁的当前事件设置不可复用的`role_authorized`证明；授权不一致统一静默拒绝。
- 能查到先查；业务口径、内容和验收问任务请求人。
- 账号、未注册workspace/权限扩张、生产、秘密、个人高权限MCP和不可恢复动作问负责人；已注册workspace由Codex按任务选择。
- 负责人回复先冻结旧发送，再区分沟通接管、任务纠正、任务接管、恢复或无关消息。
- 介入语义由独立、临时、无工具Codex回合判断固定枚举；Connector先冻结并最终执行revision，模型不能直接控制状态。语义服务异常时保守接管。

## 数据归属

```text
个人 gbrain Git        长期知识正文
gbrain PostgreSQL      可重建检索投影
Foursday 会话存储      会话和工具轨迹，由内嵌控制平面提供
Foursday 任务账本      当前岗位合同、生命周期和Evidence Manifest摘要
Foursday PostgreSQL    记忆晋升队列
项目 Git               代码、文档和交付物
```

旧 Agent Runtime、旧管理台、旧 Gateway、旧计划/审批状态机、能力预算、项目配方、影子增长指标和历史导入器不再属于当前架构。

## 版本范围

| 优先级 | 当前边界 |
|---|---|
| P0 | 个人钉钉DWS Stream/降级入口、自适应发送稳定、allowlist、开放式工作范围路由、个人gbrain关系发现、项目钉钉正本只读、Codex工作循环、语义任务合同、Thread恢复/同任务Fork、Web/Image、分层MCP、隔离Skills/Memory、子Agent、附件、五态介入、安全边界和影子验证 |
| P0 | macOS桌宠统一工作现场：顶部汇总需要我/AI负责/最近完成，侧栏以唯一项目节点展开任务；面板内次级“设置与系统诊断”统一展示钉钉、Codex、消息、gbrain、版本、证据和主动工作，技术字段默认折叠；浏览器只读页仅作隐藏应急入口；AI负责不等于Turn正在运行 |
| P1 | 桌面可见Codex Thread双模式、飞书、Slack、Teams、多平台Session，以及Hermes Cron/Monitor的产品配置入口与日报/提醒/风险预警配方 |
| P2 | 企业治理插件、配方生态、团队级策略和规模化运营能力 |

P1/P2未完成部分不应被当前安装或Release页面表述为已交付能力。详细验收以[产品需求文档](./产品需求文档.md)为准。
